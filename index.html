Live Google Sheets Sync

This dashboard reads two Google Sheets. Add rows there, run the sync, refresh the page — no Excel files, no manual export.

cd ~/call-eod-dashboard
python sync_sheets.py              # pull both sheets once
python sync_sheets.py --watch      # auto-refresh every 10 min

Or double-click update_dashboard.bat. Duplicates are blocked by call id; the write is atomic so a refresh mid-sync can never show partial data.
